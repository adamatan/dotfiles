# ELIF

Explain the topic in one short paragraph a five-year-old could follow.

## What to explain

- If the user named a topic (`/elif the changes we plan in the homepage`), explain that.
- If not, explain the last point you made: your most recent explanation, plan, or wall of text.

## Rules

- One paragraph. No headings, no lists, no code.
- Plain everyday words. Terms the reader already knows are fine: in an architecture talk, say S3, not "a place in the cloud that keeps files". Gloss only terms new to them.
- Keep every fact right. Simple, not wrong.
- Stay on point: cover only the core idea and why it matters, cut the rest.
- Do not repeat this style disclaimer or announce what you are doing. Just give the paragraph.
